# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability in **Alpemox** (such as unsafe path handling, credential exposure, or XSS in SVG/project imports), please report it privately via GitHub Security Advisories or email `hello@alpemox.dev` instead of opening a public issue.

## Supported Versions
| Version | Supported |
| :--- | :--- |
| `0.3.x` (`main`) | Yes |
