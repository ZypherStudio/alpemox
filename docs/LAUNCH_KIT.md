## 1. Hacker News — `Show HN`

**Title:**
> Show HN: Alpemox – Open-source (AGPL-3.0) local AI creative suite: 2D Photo, Bezier Vector, Video, Three.js 3D Stage & MCP

**Text / First Comment:**
> Hi HN! I built **Alpemox** (`https://github.com/ZypherStudio/alpemox`), an open-source local-first creative suite combining:
> - **3D Stage (Three.js):** Articulated mannequin posing, TransformControls gizmo, interactive OrbitSphere camera angles (adapted from ArtCraft's MIT/Apache-2.0 UI), PBR sliders, 4-angle turnaround grid, and `.GLB`/`.OBJ` export.
> - **2D Photo:** Multi-layer canvas, histogram, LUT presets, crop, background removal, Sobel edges, inline text, and inpaint mask.
> - **Vector:** Smooth Cubic Bezier with draggable anchors, Polygon/Star, CSS keyframe animated SVG export, and 1-click 3D Extrude.
> - **Film:** Multi-track `V1 + A1` timeline, motion/text keyframes, 4 WebAudio synths, and audio-mixed `.webm` export.
> - **Nodes & MCP:** Visual pipeline editor + `stdio` MCP server + CLI so agents can pose 3D mannequins and craft assets live over WebSocket.
>
> Everything runs locally for free (`npm install && npm run build && npm start` or `docker compose up`) with auto-discovery for **ComfyUI**, **A1111**, and **Ollama**, plus optional zero-key/BYOK APIs.
>
> Would love feedback on the 2D ↔ 3D ↔ AI workflow or PRs from the `good first issue` list!
